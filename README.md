# workoutmate

A clean and simple jump rope counter.

> This repository is the working target of the dsh-superagent prototype: requests
> arrive as GitHub mentions, and each request is worked on in its own session and
> branch before a pull request is opened for human review.

## Getting started

workoutmate keeps a running count of your jump rope reps so you can stay focused
on jumping.

1. Start a set when you pick up the rope.
2. Jump — the counter goes up by one for each rep.
3. Reset to zero when you are ready to start a new set.
