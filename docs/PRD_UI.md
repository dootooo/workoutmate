## 2. 产品概览

### 2.1 一句话定位

WorkoutMate 是一个**离线、无账号、端侧姿态识别**的 Android 跳绳计数 App。

### 2.2 核心价值

- 不用手动数数，摄像头自动计数
- 不需要网络、不需要账号、不上传视频
- 手机放在前方即可使用
- 支持自由跳、1 分钟、目标个数三种模式

### 2.3 当前真实状态

| 模块 | 状态 |
|---|---|
| 正式计数 | 可用；并脚跳较稳定，轮换跳仍会少计 |
| 自动暂停/恢复 | 可用 |
| 目标模式 | 可用，达到目标自动结束 |
| 1 分钟模式 | 可用，倒计时结束自动结束 |
| 中英文 | 可用，跟随系统语言 |
| 关于/隐私页 | 可用 |
| 第二阶段分类器 | 仅离线/debug 影子模式，**不是正式功能** |
| 轮换跳增强 | 仅离线原型，**不是正式功能** |

### 2.4 不应出现在用户界面的内容

- “AI 实时计数”宣传 chip：已移除，不要设计回来
- 分类器概率、候选事件数、模型版本等 debug 信息
- 屏幕录制、影子日志入口
- 尚未接入的“轮换跳自动增强”开关
- 任何“100% 准确”或“专业竞技计数”承诺

## 3. 目标用户与场景

### 3.1 主要用户

- 居家跳绳健身的普通成人
- 想记录每次跳绳数量的用户
- 不想注册账号、不想上传视频的用户
- 使用中低端 Android 手机的用户

### 3.2 典型场景

1. 把手机放在前方地面/支架上，前置摄像头拍到全身
2. 进入 App，选择模式
3. 站到取景框内，等待自动倒计时
4. 开始跳绳，看中央大数字
5. 停跳后自动暂停，继续跳 3 下恢复
6. 点击结束，看到本次结果
7. 点击重新开始或切换模式

### 3.3 使用环境

- 室内、光线稳定、背景尽量简洁
- 全身从头到脚进入画面
- 手机固定，不手持
- 单人使用；其他人进入画面会干扰识别

## 4. 设计目标与原则

### 4.1 设计目标

1. **3 秒内知道怎么开始**：首页选择模式 → 进入计数 → 站好 → 自动开始
2. **跳绳过程中只看数字**：中央计数必须是第一视觉层级
3. **状态永远明确**：等待全身、倒计时、计数中、暂停、遮挡、结束，用户随时知道发生了什么
4. **单手可操作**：底部主按钮和顶部模式切换在拇指可达范围
5. **不夸大能力**：文案承认“识别计数可能受遮挡、光线、动作影响”

### 4.2 视觉原则

- 深色运动科技感，不花哨
- 酸性荧光绿 `#D4FF4D` / `#B7FF3C` 作为主强调色
- 大面积黑/近黑背景，保证摄像头画面和白色数字清晰
- 液体 shader 只用于首页，计数页和关于页禁止使用
- 数字大、按钮大、状态文案短

### 4.3 动效原则

- 首页入场：轻微上移 + 淡入，节奏快，不阻塞操作
- 倒计时：数字切换清晰，不抖动
- 计数变化：数字直接更新，可加轻微缩放/高亮，但不能让用户看不清
- 暂停/恢复：状态 pill 变化优先，不使用全屏弹窗
- 减少动态效果时，保留状态变化，不依赖动画传达信息

## 6. 全局设计规范

### 6.1 平台与屏幕

- Android，竖屏固定
- 支持 API 24–37
- 全面屏/刘海屏：状态栏透明，内容避让系统栏
- 首页背景延伸到状态栏下方；首页文字和 ⓘ 按钮需加顶部安全区
- 计数页摄像头全屏；顶部/底部使用渐变遮罩保证文字可读

### 6.2 色彩

| Token | 值 | 用途 |
|---|---|---|
| `bg.base` | `#000000` / 近黑 | 计数页背景 |
| `bg.home` | 液体 shader / 深色渐变 | 首页背景 |
| `accent.primary` | `#D4FF4D` | 主按钮、倒计时、计时器 |
| `accent.secondary` | `#B7FF3C` | 首页 kicker、强调文字 |
| `text.primary` | `#FFFFFF` | 主标题、计数 |
| `text.secondary` | `#B3FFFFFF` | 副标题、说明 |
| `text.tertiary` | `#80FFFFFF` | 辅助提示 |
| `button.text` | `#071006` | 荧光绿按钮上的深色文字 |
| `glass.fill` | `#1FFFFFFF` | 玻璃面板 |
| `glass.stroke` | `#4DFFFFFF` | 玻璃描边 |

### 6.3 字体与字号

- 标题：Sans-serif Black / Bold，32sp
- 首页 kicker：Sans-serif Medium，11sp，字距 0.22
- 副标题：14sp，行距 3dp
- 计数数字：120sp，Bold，白色
- 倒计时：140sp，Bold，荧光绿
- 计时器：24sp，Monospace，荧光绿
- 按钮：17–18sp，Bold
- 状态 pill：14sp

### 6.4 圆角与触控

- 主按钮圆角：17dp
- 模式卡片圆角：16dp
- 圆形按钮：24dp 半径（48dp 直径）
- 最小触控区域：48dp；ⓘ 按钮 44dp 可接受
- 底部主按钮高度：56–58dp

### 6.5 布局间距

- 页面左右安全边距：24dp
- 首页标题与副标题：8dp
- 模式卡片间距：10dp
- 计数页顶部标题：24dp
- 底部主按钮离底：26–28dp

### 6.6 语言与文案

- 默认英语，`values-zh` 中文
- 跟随系统语言，不做 App 内语言切换
- 中文文案简洁、动词优先
- 英文不使用全大写长句
- 状态文案不超过两行
- 数据/隐私说明不承诺“绝对安全”，但明确“本地处理、不上传”

### 6.7 可访问性

- 正文对比度 ≥ 4.5:1
- 状态不能只用颜色区分，必须有文字
- 所有图标按钮有 `contentDescription`
- 支持系统字体缩放；计数数字在超大字号下不能溢出
- 摄像头是核心功能；无相机时明确提示，不伪装可用
- 暂停/恢复、结束/重新开始必须有文字标签，不能只靠图标

## 7. 页面需求

## 7.1 模式选择首页（ModeActivity）

### 页面目标

让用户在不阅读说明书的情况下，选择一个模式并进入计数。

### 页面结构（从上到下）

1. **背景**
   - 液体 shader 动态背景，全屏，延伸到透明状态栏下方
   - 仅此页使用 shader；不要复用到计数页/关于页

2. **顶部 kicker**
   - 中文：`Workout - 跳绳计数`
   - 英文：`Workout - Jump Rope Counter`
   - 荧光绿、小字号、宽字距

3. **主标题**
   - `选择跳绳模式` / `Choose a jump mode`
   - 32sp，白色，两行以内

4. **副标题**
   - `选择后自动识别身体并开始倒数`
   - `We'll detect your body and start the countdown automatically`

5. **三个模式卡片**
   - 自由跳绳 / Free Jump
   - 1 分钟 / 1 Minute
   - 目标个数 / Target Count
   - 卡片高度 62dp，左侧小圆点图标
   - 选中状态：更亮的描边/填充 + 明确选中标记
   - 未选中状态：玻璃质感、低对比描边

6. **目标值面板（仅“目标个数”选中时出现）**
   - 说明：`点击 − / + 调整目标次数`
   - 中间大数字：100
   - 左右圆形 `−` / `+` 按钮
   - 预设提示：`100 · 300 · 500 · 1000 · 2000`
   - 可选值固定为：100、300、500、1000、2000
   - 到达最小值/最大值时对应按钮置灰（35% 透明度），不可继续

7. **右上角 ⓘ**
   - 打开关于与隐私页
   - 44dp 触控区域，半透明白色
   - 不要放“AI 实时计数”chip

8. **底部主按钮**
   - `进入计数` / `Start Counting`
   - 荧光绿底、深色字、17sp Bold、58dp 高

### 交互

- 默认选中“自由跳绳”
- 点击模式卡片立即切换选中态
- 选择“目标个数”后，目标面板展开；选择其他模式后收起
- 点击 `进入计数` 进入计数页，携带模式和目标值
- 点击 ⓘ 进入关于页
- 首页入场动画：kicker、标题、副标题、模式组、按钮依次淡入上移

### 状态

- 默认
- 自由跳绳选中
- 1 分钟选中
- 目标个数选中 + 目标面板展开
- 目标值最小/最大（按钮置灰）
- 从计数页返回后恢复默认模式（当前实现不记忆上次模式）

### 验收

- [ ] 首页背景是液体 shader，计数页不是
- [ ] 状态栏透明，文字不被状态栏遮挡
- [ ] 三个模式均可选中，选中态明显
- [ ] 目标面板只在目标模式显示
- [ ] 目标值只能在 100–2000 的预设档位间切换
- [ ] ⓘ 在右上角且可点击
- [ ] 底部按钮在任何屏幕高度下不被导航栏遮挡

## 7.2 计数页（MainActivity）

### 页面目标

让用户专注于跳绳，只通过余光也能看到当前计数和状态。

### 页面结构

1. **全屏摄像头预览**
   - 前置摄像头，铺满屏幕
   - 顶部和底部叠加黑色渐变遮罩
   - 中央取景框 + 低透明度人体轮廓提示

2. **顶部左侧**
   - 标题：`准备开始跳绳` / `Get ready to jump`
   - 副标题：`单人模式 · 停跳 3 秒暂停 · 连跳 3 下恢复`
   - 目标模式：`目标计数 · 停跳 3 秒暂停 · 连跳 3 下恢复`
   - 1 分钟模式：`1 分钟计时 · 时间到自动结束`

3. **顶部右侧计时器**
   - 药丸形玻璃底
   - 自由/目标模式：从 `00:00` 正计时
   - 1 分钟模式：从 `01:00` 倒计时
   - 荧光绿，Monospace

4. **状态 pill**
   - 位于标题下方，显示当前状态：
     - 等待全身
     - 全身已识别，保持一下
     - 全身已识别，准备开始
     - 跳绳中
     - 已暂停，连续跳 3 下恢复
     - 目标被遮挡，等待恢复
     - 未检测到跳跃动作，等待中
     - 请让全身进入画面
     - 请后退，确保脚踝也入镜
     - 本次完成，共 N 次
     - 时间到，共 N 次
     - 目标完成，共 N 次
     - 已取消

5. **中央计数**
   - 巨大数字，120sp，白色
   - 下方单位：`次` / `jumps`，荧光绿
   - 倒计时/等待阶段隐藏计数面板，只显示引导

6. **倒计时**
   - 中央 140sp 荧光绿数字：3 → 2 → 1 → 开始/Go
   - 覆盖在摄像头画面上
   - 不阻塞状态/计时器

7. **取景引导**
   - 中央 88% 宽度的圆角框
   - 低透明度人体轮廓
   - 全身不稳定时提示“请站在框内”
   - 脚踝不可见时提示“请后退，确保脚踝也入镜”

8. **跟脚波纹**
   - 每次计数在脚部位置出现波纹
   - 前置摄像头预览镜像时，波纹位置也要镜像
   - 波纹只做反馈，不遮挡数字

9. **底部模式栏**
   - 左侧当前模式：自由跳绳 / 1 分钟 / 目标个数
   - 右侧 `切换模式`
   - 计数进行中时“切换模式”置灰（40% 透明度），结束后恢复

10. **底部主按钮**
    - 初始：`开始跳绳` / `Start Jumping`
    - 等待全身/倒计时：`取消` / `Cancel`
    - 计数中/暂停：`结束` / `Stop`
    - 结束后：`重新开始` / `Restart`

### 关键状态与行为

| 状态 | 触发 | 界面表现 | 主按钮 |
|---|---|---|---|
| 无相机权限 | 首次进入/权限被拒 | 状态提示需要权限；打开权限说明弹窗 | 授予相机权限 |
| 模型加载中 | 启动 | 状态提示加载失败（失败时禁用按钮） | 开始跳绳 |
| 等待全身 | 点击开始后 | 计数隐藏，引导框高亮，状态“请站在取景框内” | 取消 |
| 全身稳定 | 全身入镜且稳定 | 状态“已识别到全身，保持一下” | 取消 |
| 倒计时 | 全身稳定后 | 3-2-1-Go，大数字 | 取消 |
| 计数中 | 倒计时结束 | 中央计数，计时器运行，状态“跳绳中” | 结束 |
| 自动暂停 | 停跳 3 秒 | 状态“已暂停，连续跳 3 下恢复”，计数和计时器保留 | 结束 |
| 恢复 | 暂停后连跳 3 下 | 状态回到“跳绳中”，计时继续 | 结束 |
| 目标被遮挡 | 身体/关键点丢失 | 状态“目标被遮挡，等待恢复”，不计新增 | 结束 |
| 无动作 | 动作量过低 | 状态“未检测到跳跃动作，等待中” | 结束 |
| 目标完成 | 目标模式达到目标 | 状态“目标完成，共 N 次”；按钮变重新开始 | 重新开始 |
| 时间到 | 1 分钟倒计时结束 | 状态“时间到，共 N 次”；计时器 00:00 | 重新开始 |
| 手动结束 | 点击结束 | 状态“本次完成，共 N 次”；计时器显示总时长/剩余时间 | 重新开始 |
| 取消 | 等待/倒计时点击取消 | 状态“已取消” | 重新开始 |

### 关键交互

- 点击底部主按钮：
  - 未开始 → 开始等待全身
  - 等待/倒计时 → 取消
  - 计数/暂停 → 结束
  - 已结束 → 重新开始
- 结束后“切换模式”恢复可点击
- 重新开始保持当前模式和目标值
- 返回键回到模式选择页
- 计数期间保持屏幕常亮

### 验收

- [ ] 计数页任何时刻都能看到当前状态文字
- [ ] 中央数字是页面第一视觉层级
- [ ] 等待/倒计时/计数/暂停/结束状态切换不跳变
- [ ] 暂停时数字和计时保留，不归零
- [ ] 结束状态显示本次次数
- [ ] 1 分钟模式显示倒计时，时间到自动结束
- [ ] 目标模式达到目标自动结束
- [ ] 底部按钮文字随状态变化
- [ ] 摄像头出框/遮挡时有明确提示，不误显示“跳绳中”
- [ ] 波纹不遮挡数字和状态文字

## 7.3 相机权限说明（系统弹窗 + App 弹窗）

### 首次进入计数页且无权限

- App 弹窗，带相机图标
- 标题：`启用相机权限` / `Enable camera permission`
- 说明：需要相机实时识别人体姿态和计数；画面只在本地处理，不拍照、不录像、不上传；没有权限无法计数
- 按钮：
  - 主：`允许` / `Allow` → 拉起系统权限
  - 次：`暂不` / `Not now` → 留在计数页，状态提示需要权限

### 权限被永久拒绝

- App 弹窗说明需到系统设置开启
- 主按钮：`打开设置` / `Open Settings`
- 次按钮：`暂不` / `Not now`
- 返回计数页后状态仍提示权限需求，主按钮为 `授予相机权限`

### 设计要求

- 不使用全屏恐吓式权限页
- 必须说明“本地处理、不上传”
- 用户拒绝后仍可查看模式和关于页

### 验收

- [ ] 首次进入不会直接弹系统权限，先有解释弹窗
- [ ] 拒绝后 App 不崩溃、不白屏
- [ ] 永久拒绝可跳转系统设置
- [ ] 权限恢复后返回 App 可继续

## 7.4 关于与隐私页（AboutActivity）

### 页面目标

提供隐私、权限、安全、第三方许可和开发者信息，建立信任。

### 页面结构

- 顶部返回按钮
- 标题：`关于 WorkoutMate` / `About WorkoutMate`
- 版本信息：`Version X · Offline jump rope counter`
- 简介：完全离线、无账号、视频不上传
- 分区：

## 8. 关键用户流程

### 8.1 自由跳绳

```text
首页 → 自由跳绳 → 进入计数 → 等待全身 → 倒计时 → 跳绳
→ 停跳 3 秒暂停 → 连跳 3 下恢复 → 结束 → 本次完成 → 重新开始
```

### 8.2 1 分钟

```text
首页 → 1 分钟 → 进入计数 → 等待全身 → 倒计时 → 跳绳
→ 倒计时结束自动停止 → 时间到，共 N 次 → 重新开始
```

### 8.3 目标个数

```text
首页 → 目标个数 → 选择 100/300/500/1000/2000
→ 进入计数 → 等待全身 → 倒计时 → 跳绳
→ 达到目标自动停止 → 目标完成，共 N 次 → 重新开始
```

### 8.4 权限失败

```text
首页 → 进入计数 → 无权限 → 解释弹窗
→ 允许 → 系统权限 → 返回计数
或
→ 暂不 → 状态提示需要权限 → 授予相机权限
或
→ 永久拒绝 → 打开设置 → 返回 App
```

### 8.5 中途退出

```text
计数中 → 返回键 → 模式选择首页
（当前实现：退出计数页，不保留本次未结束的计数）
```

## 10. 当前产品限制（UI 必须诚实表达）

当前正式计数仍存在：

- 并脚跳通常较准；停跳后偶尔多 2–3 个
- 轮换跳（交替步）会少计，低抬腿时更明显
- 整理跳绳、甩手、挠头等停跳动作可能被误计
- 其他人员进入画面会干扰识别

因此：

- 不要设计“准确率 99%”之类的营销文案
- 结果页/关于页可以提示：“计数为运动参考，受动作、光线和遮挡影响”
- 不要在界面上暴露“当前使用第二阶段分类器”，因为尚未接入正式计数

## 14. 设计评审重点

设计稿评审时优先确认：

1. 用户是否能在 3 秒内理解“先选模式，再站进框”
2. 计数中是否只看大数字和状态就够
3. 暂停/恢复/结束是否不需要思考
4. 权限和遮挡提示是否让人知道下一步做什么
5. 是否误把 debug/研究功能画进正式流程
6. 中文和英文是否都自然、没有截断
7. 首页 shader 是否只停留在首页
